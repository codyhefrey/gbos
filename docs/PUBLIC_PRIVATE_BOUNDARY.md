# Public / Private Boundary

**Public:** SDK interfaces, API specifications, sample extensions using synthetic data, developer guides, contribution and governance documents.

**Private:** production backend implementation, proprietary AI logic, jurisdiction intelligence internals, paid modules, security operations, commercial agreements and internal deployment details.

**Never commit anywhere:** credentials, access tokens, private keys, live customer records or payment details. Store secrets in a dedicated secrets manager.

Any proposed public release must pass a human IP, privacy and secret-exposure review.
